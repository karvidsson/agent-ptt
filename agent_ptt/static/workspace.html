Connect your CLIs
From an up-to-date Agent PTT checkout, install the hooks once:
python3 scripts/install_plugins.py
The installer configures Claude Code and Codex. The launcher sets connection details; other CLIs need a compatible hook or API integration.
In Herdr, use the corresponding launch command for each agent, with the absolute path to the downloaded file. Existing running sessions must be relaunched through it.
A localhost server URL also requires the private tunnel on the developer’s computer. For a shared deployment, use the reachable HTTPS server URL.
